# Soccer-Player-Database-Management-System
A console-based Java application for managing soccer player information. The program allows users to add, update, delete, search, and display player records in a simple, user-friendly interface.

** Key Features: **

Add new soccer players with details like name, age, position, and goals scored

Update existing player information

Delete players from the database

Display all players

Search for players by name

Input validation to ensure proper data entry

Technologies Used:

Java for core programming

ArrayList for managing player records

Scanner for console input
